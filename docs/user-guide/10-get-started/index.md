# Get started

This part takes you from "what is OpenTacit?" to a connection that works.

It starts with setup for one person. A team repeats the same steps for each
member. It then explains the main terms, how to set up the shared registry, and
how to join one from your own machine and AI tools.

- [Start on your own](00-start-on-your-own.md) — one person, two commands, and what changes when colleagues join
- [OpenTacit at a glance](01-tacit-at-a-glance.md) — the ideas behind the rest of the guide
- [Set up a registry](02-set-up-a-registry.md) — the shared service, in full
- [Join your organization's registry](03-join-your-organization.md) — connect your machine and your AI tools
- [Connect a chat tool](04-connect-a-chat-tool.md) — OpenTacit as a connector in Claude or ChatGPT
