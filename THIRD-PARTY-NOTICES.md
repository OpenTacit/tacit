the published image. Anyone who redistributes that image also redistributes these
components.

**ONNX Runtime** — Copyright © Microsoft Corporation. MIT License.
<https://github.com/microsoft/onnxruntime/blob/main/LICENSE>.

The published binary statically links about thirty third-party components,

## Go dependencies

Three build configurations, three dependency sets. A default `go build` reaches
**two** direct dependencies — `modernc.org/sqlite` (the pure-Go SQLite backend)
and `golang.org/x/term`. `-tags pg` adds `github.com/jackc/pgx/v5`, the Postgres
driver; `-tags onnx` adds `github.com/yalue/onnxruntime_go`. Released binaries
and the container image carry both tags, so everything below is redistributed
with them.

The table is generated. `make licenses` fails CI when a dependency has a license
outside the project's allowlist, and `make licenses-report` regenerates this
table. See `hack/licensecheck/main.go`, which also records the two modules the

## JavaScript dependencies

None. One `package.json` is tracked (`plugins/pi/package.json`, Apache-2.0) and
it declares only `peerDependencies`, which the host supplies and this project
does not install or redistribute. There is no lockfile, no
`dependencies`, and no `node_modules` in the tree. The harness adapters are
plain `.mjs` files, and CI runs them with `node --test` and no install step.

## Cryptography and export

This software implements no cryptography of its own, and depends on no
third-party cryptographic library. Every cryptographic call reaches the Go
standard library's `crypto/...` packages: hashing and HMAC for member keys and
invitation tokens, Ed25519 for federation feed signatures, AES for stored
secrets, and `crypto/tls` plus `crypto/x509` for transport, most of it by way
of `net/http`.

No cryptographic source is included, modified or redistributed here, and the
software is not an encryption product in its own right: the cryptography is
incidental to authenticating members and signing published techniques. Anyone
redistributing a build is redistributing the Go runtime's implementation, under
Go's own BSD-3-Clause licence.

## Not distributed by this project

Frontier model APIs used for synthesis and fit-check are called at runtime under
the operator's own agreement with the provider. OpenTacit ships no model weights for
them and grants no rights to them.
